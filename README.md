# CS2 Market DE – vollständiger Frontend-Prototyp

## Start
`index.html` doppelklicken oder mit einem lokalen Webserver öffnen.

## Enthalten
- Marktplatz-Startseite im Stil des gewünschten Screenshots
- Suche und Kategorien
- Produktdetailseiten
- Warenkorb
- Demo-Kasse
- Registrierung / Login
- Benutzerkonto
- Verkäuferbereich zum Erstellen von Angeboten
- Speicherung der Demo-Daten im Browser via localStorage
- Responsive Design für PC und Smartphone

## Wichtig für eine echte Plattform
Diese Version ist bewusst ohne echten Zahlungsverkehr und ohne echtes Backend. Für den Live-Betrieb müssen u. a. Backend/Datenbank, sichere Authentifizierung, Zahlungsanbieter, E-Mail-Versand, Verkäufer-Verifizierung, Bestellabwicklung, Datenschutz/Impressum/AGB/Widerruf und ein rechtssicherer Umgang mit digitalen Gütern eingerichtet werden.

Bei Steam-/Game-Account-Angeboten solltest du außerdem die jeweils geltenden Plattformregeln und Nutzungsbedingungen prüfen.
